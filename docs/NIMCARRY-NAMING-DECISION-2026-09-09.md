# NimCarry — Naming Decision

Date: 2026-09-09
Status: LOCKED PUBLIC-FACING BRAND

## Decision

The product previously presented as **Carry One** is now named **NimCarry**.

Primary public tagline:

> **One NIM. One bridge at a time.**

Primary promise remains:

> **Get this to someone you cannot reach directly — one human bridge at a time.**

## Why

The `Nim` prefix makes the Mini App's Nimiq-native identity immediately legible while `Carry` preserves the core product metaphor: a mission is carried from consenting human bridge to consenting human bridge until its defined destination becomes the finalized recipient.

The rename does **not** change the frozen product law, custody semantics, target policy, exact 1 NIM baton, FINAL-only advancement, ARRIVED terminal state, security model, or current execution gates.

## Migration boundary

Public-facing product identity changes immediately to **NimCarry**.

For Cycle II continuity, the following technical identifiers remain temporarily stable until a controlled migration can be done without breaking the active demo, Opeyemi's branch, deployment routing, test fixtures, or local/session storage:

- GitHub repository slug: `Faadil1/carry-one`
- current Vercel demo URL: `https://carry-one-sip-show.vercel.app/?demo=1`
- internal `carryone.*` browser storage keys
- existing function/type identifiers whose rename would create unnecessary merge risk
- historical evidence filenames and prior milestone records

This is intentional compatibility, not a second product name.

## Judge-facing language

**NimCarry turns an invisible chain of human introductions into a consented, verifiable human route, using exactly 1 NIM as the baton.**

The baton is not a reward, prize, investment, wager, or forwarding incentive. It represents custody of the mission. Custody changes only after verified finality.

## Presentation rule

From this decision forward, new public copy, decks, demo narration, submission material, screenshots, promotion posts, and judge-facing UI should use **NimCarry**. Historical records may retain `Carry One` where changing them would falsify or obscure the evidence trail.
